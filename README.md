# Python List Manipulation Practice

A beginner Python project exploring lists and basic programming concepts.

## Features
- Displays a list of programming languages.
- Shows the first, last and indexed elements.
- Allows users to enter a new programming language.
- Randomly selects and replaces an existing list item.
- Uses a loop to repeatedly run the program.
- Allows users to exit the program.

## Concepts Practised
- Lists
- While loops
- For loops
- `enumerate()`
- Conditional statements (`if`, `elif`, `else`)
- User input
- Random number generation
- List indexing and replacement
- String methods (`strip()` and `lower()`)

## Technologies
- Python
- Python Random module

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run:

```bash
python python_list_practice.py
```

This project was created as part of my independent Python learning, with the aim of strengthening my understanding of lists, loops and user interaction.
